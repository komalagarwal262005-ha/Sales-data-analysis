# SALES DATA ANALYSIS
AI Academia Internship | Komal Agarwal | September 2026

## ABOUT
Analysis of retail sales data covering trends, top products, regional performance, and ML-based sales prediction.

## TOOLS USED
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, SciPy

## DATASET
The dataset contains 1000+ rows of retail sales records with columns like Order Date, Product Category, Region, Sales Amount, and Profit. The data covers monthly trends from 2023-2024.

## KEY FINDINGS
1. Sales show a strong seasonal trend with peak in Q4.
2. Electronics is the top-performing category.
3. Top 3 products contribute to over 60% of total revenue.
4. Linear Regression model achieved R2 score of 0.85 for sales prediction.
5. Classification model predicted high-sales regions with 88% accuracy.
